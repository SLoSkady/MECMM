# MECMM — Mirror's Edge Catalyst Multiplayer Mod

[English](README.md) · **Русский**

Неофициальный мультиплеерный мод для **Mirror's Edge Catalyst** (ПК, Steam), в разработке.
Цель: видеть других бегунов в своей игре в реальном времени, соревноваться с ними, вместе
бегать по городу, играть в «пятнашки».

> [!WARNING]
> Ранняя стадия разработки. Игроки подключаются к серверу и видят друг друга в мире в виде
> **простых 3D-фигур** с ником и расстоянием; за стенами фигуры прячутся (видно бледный
> силуэт). Настоящая модель персонажа игры пока не используется.
> Подробнее в разделе [План](#план).

## Требования

- Windows 10/11 x64
- Mirror's Edge Catalyst, версия **Steam** (другие не проверялись)
- Для сборки: Visual Studio 2022 с компонентом **«Разработка классических приложений на C++»** (CMake входит в него), Git

## Установка

1. Соберите мод (см. [Сборка](#сборка)) или возьмите `dinput8.dll` из релиза, когда он появится.
2. **Закройте игру** и запустите:
   ```bat
   scripts\install.bat "D:\путь\к\Mirrors Edge Catalyst"
   ```
   (без аргумента используется `E:\SteamLibrary\steamapps\common\Mirrors Edge Catalyst`)
3. Запустите игру. В левом верхнем углу появится окно **MECMM**. **F7** прячет и показывает
   его, **F8** открывает окно отладки глубины. Клавиши меняются в `mecmm.ini`
   (`[keys] menu=F7`, `debug=F8`; названия вида `F1`..`F12`, `Home`, `End`, `PageUp`, `K`, `5`).

Чтобы удалить мод, закройте игру и запустите `scripts\uninstall.bat`: игра вернётся в исходное состояние.

> [!NOTE]
> В декабре 2023 года EA отключила онлайн-серверы игры. Если после вступительного ролика
> бесконечная загрузка, запустите игру с **отключённым интернетом** и включите его, когда игра загрузится.

## Сборка

```bat
git clone --recursive https://github.com/SLoSkady/MECMM.git
cd MECMM
scripts\build.bat
```

Результат в `build\Release\`: `dinput8.dll` (мод), `mecmm-server.exe` (сервер-ретранслятор),
`mecmm-bot.exe` (тестовый бот). Библиотеки (ImGui, MinHook) подключены как подмодули Git и
скачиваются автоматически.

## Игра вместе

Один человек запускает сервер, все (включая его самого) подключаются к нему из игры.

1. **Хост:** запустите `scripts\run-server.bat`. Сервер слушает UDP-порт **47777**.
   Для игроков не из вашей локальной сети разрешите сервер в брандмауэре Windows и пробросьте
   UDP-порт 47777 на роутере.
2. **Все игроки:** после первого запуска мод создаёт в папке игры файл `mecmm.ini`:
   ```ini
   [net]
   server=127.0.0.1   ; IP-адрес хоста (127.0.0.1 — этот же компьютер)
   port=47777
   name=Runner        ; ваш ник
   [keys]
   menu=F7            ; показать/спрятать окно MECMM
   debug=F8           ; окно отладки глубины
   ```
   Измените его и перезапустите игру.
3. В игре окно MECMM показывает **Online** и список других игроков с расстоянием до них.

**Проверка в одиночку:** запустите `scripts\run-server.bat` и `scripts\run-bot.bat`, затем игру.
Бот подключится как второй игрок и будет бегать кругами в 5 метрах вокруг вас.

## Как это работает

1. Игра загружает `dinput8.dll` из своей папки. Наша версия передаёт все вызовы DirectInput
   настоящей системной `dinput8.dll` (управление продолжает работать) и запускает мод в отдельном потоке.
2. Мод перехватывает `IDXGISwapChain::Present` (через MinHook) и каждый кадр рисует свой
   интерфейс поверх картинки с помощью Dear ImGui.
3. Позиция игрока читается по маршруту указателей, найденному реверс-инжинирингом:
   `[MirrorsEdgeCatalyst.exe + 0x23DA020] + 0x730`. Подробности в
   [docs/research/findings.md](docs/research/findings.md) (на английском).
4. Сетевой поток 30 раз в секунду отправляет позицию и направление игрока на сервер по UDP.
   Сервер пересылает состояние каждого игрока всем остальным и отключает тех, от кого
   5 секунд нет вестей. Формат сообщений описан в [src/net/protocol.h](src/net/protocol.h).
5. Другие игроки рисуются с задержкой 100 мс с плавным переходом между полученными позициями
   и переводятся в точки экрана с помощью матриц камеры самой игры
   (`[MirrorsEdgeCatalyst.exe + 0x2563A10]`: вид `+0x630`, проекция `+0x6F0`).

## Структура проекта

```
MECMM/
├── src/                    исходный код мода (C++20), собирается в dinput8.dll
│   ├── core/               точка входа, прокси dinput8, настройки (mecmm.ini), сетевая сессия, журнал
│   ├── game/               доступ к данным игры (позиция и направление игрока)
│   ├── net/                сетевой протокол и UDP-клиент (общие с сервером и ботом)
│   ├── overlay/            перехват Present (D3D11) и интерфейс ImGui
│   └── render/             поиск буфера глубины, 3D-фигуры других игроков
├── server/                 отдельные программы
│   ├── relay/              mecmm-server.exe — сервер-ретранслятор
│   └── bot/                mecmm-bot.exe — тестовый бот, бегающий вокруг игрока
├── external/               сторонние библиотеки (подмодули Git)
│   ├── imgui/              Dear ImGui v1.91.5
│   └── minhook/            MinHook v1.3.3
├── scripts/                сборка, установка/удаление, запуск сервера и бота
├── tools/                  инструменты для исследования игры (PowerShell)
│   ├── memory/             сканеры памяти, поиск указателей, просмотр позиции
│   ├── sdk/                дампер SDK (описания типов движка → текстовые файлы)
│   ├── disasm/             дизассемблер расшифрованного кода игры
│   ├── lib/                библиотека дизассемблера Iced
│   └── output/             сырые данные сканов (не попадают в репозиторий)
└── docs/
    └── research/           результаты исследований, таблицы Cheat Engine, скриншоты
```

## Инструменты исследования

Все инструменты читают память запущенной игры, дополнительно ничего ставить не нужно.

| Инструмент | Назначение |
|---|---|
| `tools/memory/showpos.ps1` | Показать позицию игрока по известному маршруту (`-Watch` — в реальном времени) |
| `tools/memory/heightscan.ps1` | Поиск значений как в Cheat Engine (выросло / уменьшилось / не изменилось) по **всей** памяти потоком — работает там, где Cheat Engine не хватает памяти |
| `tools/memory/posscan.ps1` | Поиск троек координат x,y,z и отсев по движению |
| `tools/memory/memwatch.ps1` | Запись значений в CSV, пока окно игры активно |
| `tools/memory/ptrfind.ps1` | Поиск указателей на объект; отмечает постоянные (внутри `.exe`) |
| `tools/memory/ptrchain.ps1` | Многоуровневый поиск цепочек указателей до постоянных мест в `.exe` (как Pointer scan в CE) |
| `tools/memory/matscan.ps1` | Поиск матриц положения 4x4 рядом с точкой и отсев по повороту |
| `tools/memory/strscan.ps1` | Поиск строк (имён типов движка, ресурсов) в памяти игры |
| `tools/memory/findbytes.ps1` | Поиск точной строки или значения указателя в памяти игры |
| `tools/sdk/sdkdump.ps1` | **Дампер SDK**: все ~10 000 классов, структур и перечислений движка с полями и смещениями → `tools/output/sdk/` |
| `tools/sdk/instances.ps1` | Поиск живых объектов класса движка (например `-Class PamClientReplayPlayerComponent`) |
| `tools/sdk/inspect.ps1` | Содержимое живого объекта с именами классов по указателям |
| В игре: **F8** | Окно отладки с буферами глубины игры (PgUp/PgDn — листать) |
| `tools/disasm/disasm.ps1` | Дизассемблировать код игры вокруг адреса |
