# MECMM — Mirror's Edge Catalyst Multiplayer Mod

[English](README.md) · **Русский**

Неофициальный мультиплеерный мод для **Mirror's Edge Catalyst** (ПК, Steam), в разработке.
Цель: видеть других бегунов в своей игре в реальном времени, соревноваться с ними, вместе
бегать по городу, играть в «пятнашки».

> [!WARNING]
> Ранняя стадия разработки. **Мультиплеера пока нет**: сейчас мод показывает позицию игрока
> во внутриигровом окне. Подробнее в разделе [План](#план).

## Требования

- Windows 10/11 x64
- Mirror's Edge Catalyst, версия **Steam** (другие не проверялись)
- Для сборки: Visual Studio 2022 с компонентом **«Разработка классических приложений на C++»** (CMake входит в него), Git

## Установка

1. Соберите мод (см. [Сборка](#сборка)) или возьмите `dinput8.dll` из релиза, когда он появится.
2. **Закройте игру** и запустите:
   ```bat
   scripts\install.bat "D:\путь\к\Mirrors Edge Catalyst"
   ```
   (без аргумента используется `E:\SteamLibrary\steamapps\common\Mirrors Edge Catalyst`)
3. Запустите игру. В левом верхнем углу появится окно **MECMM**. Клавиша **Insert**
   прячет и показывает его.

Чтобы удалить мод, закройте игру и запустите `scripts\uninstall.bat`: игра вернётся в исходное состояние.

> [!NOTE]
> В декабре 2023 года EA отключила онлайн-серверы игры. Если после вступительного ролика
> бесконечная загрузка, запустите игру с **отключённым интернетом** и включите его, когда игра загрузится.

## Сборка

```bat
git clone --recursive https://github.com/SLoSkady/MECMM.git
cd MECMM
scripts\build.bat
```

Результат: `build\Release\dinput8.dll`. Библиотеки (ImGui, MinHook) подключены как
подмодули Git и скачиваются автоматически.

## Как это работает

1. Игра загружает `dinput8.dll` из своей папки. Наша версия передаёт все вызовы DirectInput
   настоящей системной `dinput8.dll` (управление продолжает работать) и запускает мод в отдельном потоке.
2. Мод перехватывает `IDXGISwapChain::Present` (через MinHook) и каждый кадр рисует свой
   интерфейс поверх картинки с помощью Dear ImGui.
3. Позиция игрока читается по маршруту указателей, найденному реверс-инжинирингом:
   `[MirrorsEdgeCatalyst.exe + 0x23DA020] + 0x730`. Подробности в
   [docs/research/findings.md](docs/research/findings.md) (на английском).

## Структура проекта

```
MECMM/
├── src/                    исходный код мода (C++20), собирается в dinput8.dll
│   ├── core/               точка входа, прокси dinput8, журнал
│   ├── game/               доступ к данным игры (позиция игрока)
│   └── overlay/            перехват Present (D3D11) и интерфейс ImGui
├── external/               сторонние библиотеки (подмодули Git)
│   ├── imgui/              Dear ImGui v1.91.5
│   └── minhook/            MinHook v1.3.3
├── scripts/                build.bat, install.bat, uninstall.bat
├── tools/                  инструменты для исследования игры (PowerShell)
│   ├── memory/             сканеры памяти, поиск указателей, просмотр позиции
│   ├── disasm/             дизассемблер расшифрованного кода игры
│   ├── lib/                библиотека дизассемблера Iced
│   └── output/             сырые данные сканов (не попадают в репозиторий)
└── docs/
    └── research/           результаты исследований, таблицы Cheat Engine, скриншоты
```

## Инструменты исследования

Все инструменты читают память запущенной игры, дополнительно ничего ставить не нужно.

| Инструмент | Назначение |
|---|---|
| `tools/memory/showpos.ps1` | Показать позицию игрока по известному маршруту (`-Watch` — в реальном времени) |
| `tools/memory/heightscan.ps1` | Поиск значений как в Cheat Engine (выросло / уменьшилось / не изменилось) по **всей** памяти потоком — работает там, где Cheat Engine не хватает памяти |
| `tools/memory/posscan.ps1` | Поиск троек координат x,y,z и отсев по движению |
| `tools/memory/memwatch.ps1` | Запись значений в CSV, пока окно игры активно |
| `tools/memory/ptrfind.ps1` | Поиск указателей на объект; отмечает постоянные (внутри `.exe`) |
| `tools/disasm/disasm.ps1` | Дизассемблировать код игры вокруг адреса |
